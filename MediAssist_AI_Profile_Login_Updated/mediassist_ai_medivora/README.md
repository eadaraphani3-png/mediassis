# MediAssist AI Medivora

## Medical Decision Support System

MediAssist AI Medivora is an academic capstone project designed to provide preliminary health guidance through an interactive web application.

### Features
- Symptom information and preliminary guidance
- Patient intake workflow
- Safety checks and emergency guidance
- Hospital routing information
- Health record and reminder features, where configured

### Technology Stack
- Python
- HTML, CSS, and JavaScript
- SQLite database
- Python agent modules

### Installation

1. Install Python 3 on your computer.
2. Open PowerShell in the project directory.
3. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Start the application using the appropriate command for the framework configured in `app.py`.

### Safety Notice

This project is intended for educational and demonstration purposes. It does not replace professional medical advice, diagnosis, or treatment. In an emergency, contact local emergency services.
